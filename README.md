# 地形分析器 · Terrain Analyzer

> 圈选一块区域，自动生成地形统计、坡度分析、高程剖面与地形特征解读 —— 让复杂地形一眼可读。

`星球小捕手` 旗下在线地理工具。打开网页 → 在地图上圈选区域 → 点击分析 → 秒级得到一份包含地图、图表与文字解读的地形分析报告。**全部计算在浏览器本地完成，地形数据不上传任何服务器。**

---

## ✨ 核心功能

### 区域圈选
- 支持**矩形框选**与**多边形手绘**两种选区方式，最多 100 个顶点。
- 自动限制分析面积（默认上限 100 km²），超出即提示缩小范围；自相交多边形禁止分析。
- 地名搜索（高德地理编码 + Nominatim 兜底），一键飞抵目标区域。

### 地形指标（来自真实 DEM 计算）
面积、最低/最高/平均海拔、最大高差、平均/最大坡度、各坡度等级面积占比、高程分布直方图。

### 地形图层（可下拉切换）
| 图层 | 说明 |
| --- | --- |
| **等高线**（默认） | Marching Squares 生成，计曲线加粗，自动剔除水域噪声与孤立小圈 |
| 高程 | 连续色带反映绝对高度 |
| 分层设色 | 分级色带，地形图通用配色 |
| 晕渲 | 分层设色叠加山体阴影，立体感最强 |
| 山体阴影 | 纯灰度，只看坡形不看高度 |
| 坡度 | 按陡缓程度分级 |
| 坡向 | 坡面朝向（北红 / 南青） |

### 派生分析（D8 水文模型 + 曲率 + 通视）
- **河网水系**：Priority-Flood 填洼 → D8 流向 → 汇流累积 → 自适应阈值提取河网与河网密度。
- **地形湿度指数 (TWI)**：`ln(比汇水面积 / tanβ)`，固定断点分级，可横向比较。
- **曲率**：Zevenbergen & Thorne 平面/剖面曲率，识别山脊（凸）与谷底（凹）。
- **视域分析 (Viewshed)**：射线扫描，修正地球曲率与大气折射，默认 2m 人眼高度。

### 高程剖面
在地图上绘制任意一条线，沿线采样 DEM，生成高程剖面图，并给出：线路距离、最高/最低点、累计爬升、累计下降、平均坡度。

### 极端点交互
地图自动标注**最高点**与**最低点**；点击圆点弹出说明卡片，解释其含义（海拔、坐标、在地形分析中的作用）。

### 结果导出
- **PNG**：`项目名-YYYYMMDD-HHmm.png` 格式。
- **PDF 报告**：整份报告用 Canvas 2D 排版（系统 CJK 字体），彻底解决 jsPDF 中文字体缺失问题，含区域地图、基础指标、坡度/高程分析、剖面图与地形特征解读。

### 底图
默认**高德卫星影像**置首，路网与注记默认显示；另含高德矢量、OSM、Esri 卫星、Esri 地形。

### 其他
- **移动端适配**：窄屏结果卡片顶部横条点击即可展开/收起。
- **本地持久化**：项目自动存入 IndexedDB，刷新或重开浏览器不丢失。
- **隐私优先**：纯前端 SPA，无登录、无后端、无数据上传。

## 🧱 技术栈

| 领域 | 选型 |
| --- | --- |
| 框架 | React 18 + TypeScript + Vite 5 |
| 地图 | MapLibre GL JS 4（栅格瓦片，高德底图直连免 key） |
| 图表 | ECharts 5（按需引入） |
| 空间计算 | @turf/turf |
| 报告导出 | 自研 Canvas 2D → PDF 引擎（替代 jsPDF，零中文字体依赖） |
| 重计算 | Web Worker（不阻塞 UI） |
| 持久化 | IndexedDB |

**DEM 数据源**：Open-Meteo Elevation API（Copernicus GLO-30 / GLO-90），Terrarium 瓦片作为备选。`DEMProvider` 抽象层已与业务解耦，可随时替换数据源。

## 🚀 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 类型检查 + 生产构建
npm run build

# 预览构建产物
npm run preview
```

构建产物输出到 `dist/`，可直接托管到任意静态服务器（Cloudflare Pages、GitHub Pages、Nginx 等）。

> **部署提示**：`public/404.html` 已内置，可关闭 CDN 的「自动 SPA 模式」软 404，确保未命中路径返回真实 404，利于搜索引擎收录与 IndexNow 校验。

## 📁 项目结构

```
src/
├── components/        # UI 组件（地图、选区、结果面板、图表、剖面、视域等）
├── services/
│   ├── dem/           # DEM 数据提供层（Open-Meteo / Terrarium）
│   ├── terrain/       # 地形算法（高程/坡度/曲率/水文/剖面/视域/描述）
│   └── export/        # PDF / PNG 报告导出
├── workers/           # Web Worker：重计算在后台线程执行
├── utils/             # 坐标变换(CRS)、配色、格式化、设备判定等
├── types/             # 共享类型
├── config.ts          # 站点归属、底图 KEY 等配置（单一来源）
├── App.tsx            # 应用主流程
└── index.css          # 全局样式
```
